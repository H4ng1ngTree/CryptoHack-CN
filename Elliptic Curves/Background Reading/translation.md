# Background Reading

**5 分 - 7039 人解决**

来源：<https://cryptohack.org/challenges/ecc/>

## 中文翻译

这道导论题介绍椭圆曲线密码学的基本动机，并引入短 Weierstrass 形式的椭圆曲线：

$$
E : Y^2 = X^3 + aX + b
$$

题面从几何角度说明点加法：给定曲线上的两个点，作一条经过它们的直线，找到直线与曲线的第三个交点，再将该点反射，从而得到两点之和。若计算同一点与自身相加，则使用该点处的切线。

无穷远点 $O$ 在椭圆曲线群中充当单位元。该群运算满足：

```text
P + O = O + P = P
P + (-P) = O
(P + Q) + R = P + (Q + R)
P + Q = Q + P
```

在有限域上的椭圆曲线中，曲线被视为坐标属于 $\mathbb{F}_p$ 的有限点集，并额外包含无穷远点 $O$。

本题要求填写满足交换律的群的数学名称。
