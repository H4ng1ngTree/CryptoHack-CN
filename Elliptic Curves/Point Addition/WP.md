## Hint

- 无穷远点 $O$ 没有普通的数值坐标，可以在 Python 中用 `None` 表示。
- Python 原生支持元组，所以普通点可以直接写成坐标二元组。
- 因为题目工作在有限域 $\mathbb{F}_p$ 中，所有坐标计算都要对 $p$ 取模。
- 有限域里不能直接使用普通除法。公式里的除法要换成“乘以模逆元”。

## 思路

题目要算的是：

$$
S = P + P + Q + R
$$

所以核心就是把点加法函数写对，然后按顺序调用三次。

需要注意两种特殊情况：

- 如果其中一个点是无穷远点 $O$，直接返回另一个点。
- 如果两个点互为相反点，那么结果就是 $O$。

普通加法和倍点都用题面给出的公式，只是所有除法都要换成“乘以模逆元”。
