# Point Addition

**30 分 - 5444 人解决**

## 中文翻译

本题要求在有限域上实现椭圆曲线的点加法法则。

## 两点相加算法：$P + Q$

```text
(a) 如果 P = O，那么 P + Q = Q。
(b) 否则，如果 Q = O，那么 P + Q = P。
(c) 否则，记 P = (x_1, y_1)，Q = (x_2, y_2)。
(d) 如果 x_1 = x_2 且 y_1 = -y_2，那么 P + Q = O。
(e) 否则：
    (e1) 若 P != Q：lambda = (y_2 - y_1) / (x_2 - x_1)
    (e2) 若 P = Q：lambda = (3x_1^2 + a) / 2y_1
(f) x_3 = lambda^2 - x_1 - x_2
(h) y_3 = lambda(x_1 - x_3) - y_1
(i) P + Q = (x_3, y_3)
```

> 在有限域中，所有运算都应在模 $p$ 的意义下进行。这里的除法应通过乘以模逆元来实现；例如，$5^{-1} \equiv 9 \pmod{11}$。

使用如下曲线：

$$
E : Y^2 = X^3 + 497X + 1768 \pmod{9739}
$$

> 测试数据：当 $X=(5274,2841)$、$Y=(8669,740)$ 时，应验证 $X+Y=(1024,4440)$，并且 $X+X=(7284,2107)$。

给定：

$$
P=(493,5564),\quad Q=(1539,4742),\quad R=(4403,5202)
$$

求：

$$
S(x,y)=P+P+Q+R
$$

> 计算得到 $S$ 后，请验证它确实属于 $E(\mathbb{F}_p)$。

在此输入 flag：`crypto{x,y}`
