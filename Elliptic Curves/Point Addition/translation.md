# 点加法

30 分 · 5449 人解决

在研究椭圆曲线密码学时，我们需要对曲线上的点进行加法运算。在背景题中，我们曾用几何方式完成这件事：先找到一条经过两个点的直线，再求出它与曲线的第三个交点，最后将该交点关于 x 轴作镜像。

事实上，椭圆曲线的点加法法则可以通过一个高效算法来计算。

下面的算法摘自 Jeffrey Hoffstein、Jill Pipher 与 Joseph H. Silverman 合著的 *An Introduction to Mathematical Cryptography*，它可以用于计算椭圆曲线上两个点的和。

## 两点相加算法：`P + Q`

(a) 如果 `P = O`，那么 `P + Q = Q`。

(b) 否则，如果 `Q = O`，那么 `P + Q = P`。

(c) 否则，记 `P = (x_1, y_1)`，`Q = (x_2, y_2)`。

(d) 如果 `x_1 = x_2` 且 `y_1 = -y_2`，那么 `P + Q = O`。

(e) 否则：

- (e1) 若 `P ≠ Q`，则 `λ = (y_2 - y_1) / (x_2 - x_1)`；
- (e2) 若 `P = Q`，则 `λ = (3x_1^2 + a) / 2y_1`。

(f) `x_3 = λ^2 - x_1 - x_2`

(h) `y_3 = λ(x_1 - x_3) - y_1`

(i) `P + Q = (x_3, y_3)`

由于我们现在是在有限域上运算，所以上述所有计算都应当在模 `p` 的意义下进行。这里并不是直接对整数做“除法”，而是乘以相应数的模逆元。例如：`5^{-1} ≡ 9 mod 11`。

本题使用如下椭圆曲线与素数模数：

```text
E: Y^2 = X^3 + 497X + 1768 mod 9739
```

你可以用下面的断言测试自己的算法：当 `X = (5274, 2841)`、`Y = (8669, 740)` 时，应有 `X + Y = (1024, 4440)`，并且 `X + X = (7284, 2107)`。

使用上述曲线，以及三个点 `P = (493, 5564)`、`Q = (1539, 4742)`、`R = (4403, 5202)`，请实现上面的算法，并计算点 `S(x, y) = P + P + Q + R`。

计算得到 `S` 后，将其坐标代回曲线方程中，验证该点确实属于 `E(F_p)`。
