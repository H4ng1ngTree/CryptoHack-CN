# 点加法

**30 分 · 5449 人解决**

在椭圆曲线密码学中，我们需要对曲线上的点进行加法运算。在前置背景题中，我们曾经用几何方式完成这一过程：先作一条经过两个点的直线，找到它与曲线的第三个交点，然后再将该交点关于 $x$ 轴反射。

事实上，椭圆曲线上的点加法法则可以通过一种高效算法来计算。

下面的算法摘自 Jeffrey Hoffstein、Jill Pipher 与 Joseph H. Silverman 合著的 *An Introduction to Mathematical Cryptography*，它可以用于计算椭圆曲线上两个点的和。

---

## 两点相加算法：$P + Q$

```text
(a) 如果 P = O，那么 P + Q = Q。

(b) 否则，如果 Q = O，那么 P + Q = P。

(c) 否则，记 P = (x₁, y₁)，Q = (x₂, y₂)。

(d) 如果 x₁ = x₂ 且 y₁ = -y₂，那么 P + Q = O。

(e) 否则：

    (e1) 若 P ≠ Q：λ = (y₂ - y₁) / (x₂ - x₁)

    (e2) 若 P = Q：λ = (3x₁² + a) / 2y₁

(f) x₃ = λ² - x₁ - x₂

(h) y₃ = λ(x₁ - x₃) - y₁

(i) P + Q = (x₃, y₃)
```

> 由于我们现在是在有限域中工作，所以上述计算都应在模 $p$ 的意义下进行。这里的“除以某个整数”并不是普通意义上的除法，而是乘以该数在模 $p$ 下的乘法逆元。例如：$5^{-1} \equiv 9 \pmod{11}$。

本题使用如下椭圆曲线和素数模数：

$$
E: Y^2 = X^3 + 497X + 1768 \pmod{9739}
$$

> 你可以用以下断言测试自己的算法：当 $X = (5274, 2841)$、$Y = (8669, 740)$ 时，应有 $X + Y = (1024, 4440)$，并且 $X + X = (7284, 2107)$。

基于上述曲线，以及三个点 $P = (493, 5564)$、$Q = (1539, 4742)$、$R = (4403, 5202)$，请实现上述算法，并求出点 $S(x, y) = P + P + Q + R$。

> 计算得到 $S$ 后，请将其坐标代回曲线方程中，验证该点确实属于 $E(\mathbb{F}_p)$。

在此输入 flag：`crypto{x,y}`
